Octarq 内置 3 个原生 LLM 驱动（Anthropic、Gemini、OpenAI 兼容），覆盖 27 个供应商。

## 快速设置

```bash
# 选一个供应商 — 设置环境变量 — 完成
export GEMINI_API_KEY="your-key"        # 有免费套餐
# 或
export GROQ_API_KEY="your-key"          # 有免费套餐
# 或
export ANTHROPIC_API_KEY="your-key"
# 或
export OPENAI_API_KEY="your-key"
```

启动时自动检测已配置密钥的供应商。本地供应商 (Ollama, vLLM, LM Studio) 无需密钥。

## Per-Agent 模型覆盖

每个 Agent 可以使用不同的供应商：

```toml
[model]
provider = "openai"
model = "gpt-4o"
api_key_env = "OPENAI_API_KEY"
```

## 模型别名

常用快捷方式：

| 别名 | 实际模型 |
