Octarq ships with 3 native LLM drivers (Anthropic, Gemini, OpenAI-compatible), covering 27 providers.

## Quick Setup

```bash
# Pick a provider — set the env var — done
export GEMINI_API_KEY="your-key"        # Has a free tier
# Or
export GROQ_API_KEY="your-key"          # Has a free tier
# Or
export ANTHROPIC_API_KEY="your-key"
# Or
export OPENAI_API_KEY="your-key"
```

Providers with configured keys are auto-detected at startup. Local providers (Ollama, vLLM, LM Studio) need no keys.

## Per-Agent Model Override

Each agent can use a different provider:

```toml
[model]
provider = "openai"
model = "gpt-4o"
api_key_env = "OPENAI_API_KEY"
```
