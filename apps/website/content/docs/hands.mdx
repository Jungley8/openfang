**Hand** 是 Octarq 的核心创新 — 预构建的自主能力包，按计划独立运行，无需你提示。这不是聊天机器人。这是一个会在早上 6 点自动醒来、研究你的竞争对手、构建知识图谱、评分发现，并在你喝咖啡之前把报告发到 Telegram 的 Agent。

每个 Hand 包含：
- **HAND.toml** — 清单：声明工具、设置、需求和仪表盘指标
- **系统提示** — 多阶段操作手册 (500+ 字的专家流程)
- **SKILL.md** — 运行时注入的领域知识
- **护栏** — 敏感操作的审批门

全部编译进二进制文件。无需下载，无需 pip install，无需 Docker pull。

## 7 个内置 Hand

### Clip
接收 YouTube URL，下载、识别精彩时刻、剪切为竖版短视频（带字幕和缩略图），可选添加 AI 配音，发布到 Telegram 和 WhatsApp。8 阶段流水线，FFmpeg + yt-dlp + 5 个 STT 后端。

### Lead
每日运行。发现匹配你 ICP 的潜在客户，用网络研究丰富信息，评分 0-100，与现有数据库去重，以 CSV/JSON/Markdown 交付合格线索。

### Collector
OSINT 级情报。给它一个目标（公司、人物、话题），它持续监控 — 变化检测、情感追踪、知识图谱构建，关键变化时发出警报。

### Predictor
超级预测引擎。收集多源信号，构建校准推理链，给出带置信区间的预测，用 Brier 分数追踪自身准确率。有逆向思维模式。

### Researcher
深度自主研究。交叉引用多个来源，用 CRAAP 标准评估可信度，生成引用的报告（APA 格式），支持多语言。

### Twitter
自主 Twitter/X 管理。7 种轮换格式创建内容，安排最佳发布时间，回应提及，追踪效果指标。有审批队列 — 不经你确认不会发布。

### Browser
Web 自动化。导航网站、填表、点击、处理多步工作流。使用 Playwright + 会话持久化。**强制购买审批门** — 永远不会在没有确认的情况下花你的钱。

## 使用方式

```bash
# 激活 Researcher Hand — 立即开始工作
openfang hand activate researcher

# 查看进度
openfang hand status researcher

# 每日计划激活 Lead
openfang hand activate lead

# 暂停 (不丢失状态)
openfang hand pause lead

# 查看所有可用 Hand
openfang hand list
```

## 构建自己的 Hand

定义一个 `HAND.toml`，配置工具、设置和系统提示：

```toml
name = "my-hand"
version = "0.1.0"
description = "自定义 Hand"

[telos]
mode = "focused"
max_chars = 3000

[schedule]
mode = "periodic"
interval = "6h"

[[tools]]
name = "web_search"

[[tools]]
name = "web_fetch"
```
